## Preamble

SeatWatch is one accountable human (Nathan), a small set of AI agents, and a deterministic program on one free VM. It has 763 live schools and zero external users; its only real asset is the true claim that its alerts never lie. This document is the entire operating law. It obeys two honesty rules about itself: **it describes reality, not intentions** — anything it requires that is not yet built appears, numbered, in `~/seatwatch/BLOCKERS.md`, and no clause is "in force" until its machinery exists (safety powers excepted, as stated where they appear) — and **every role, gate, and ritual names the failure it prevents**; anything that can't is repealed on sight.

Ratification is not a signature; it executes five same-day acts, **in this order** (the order is law — act 3 must not ship over a dirty tree): (1) one safe backup — on the VM, `sqlite3 watches.db ".backup /tmp/seatwatch.bak"`, then scp **that copy** to `~/SeatWatchVault/` on your Mac — the first backup watches.db has ever had (a raw scp of the live file can produce a torn, silently corrupt copy; the `.backup` command cannot); (2) Build commits or resolves **all in-flight work** — the uncommitted TAMU-CC adapter, the untracked patches and drafts — until `git status` is clean; (3) only then, the daily term auto-roll is **disarmed** via one small deploy shipped under the interim deploy rule below (clean `git status` pasted into the handoff, your go); (4) removal of the fabricated testimonial is queued for your one-line go; (5) you sign the named Repeals at the end of this document.

## Principles

1. **Never a false "open," never a silent miss — and when we are blind, the user is told.** Fetchers return nothing on doubt; fail closed; bias late. Blindness the watcher can't see is a silent miss, so broken or term-stale watches must page the operator *and* tell the user.
2. **Deterministic code > AI agent > human.** Anything repeatable is code. AI does judgment, research, and repair. You do only what is legally or reputationally yours alone.
3. **Your attention is the budget.** Everything reaching you arrives on one channel, shaped as a yes/no or a one-glance summary — never logs, diffs, or code. Target: a 2-minute daily glance plus one 30-minute Monday sitting.
4. **One writer per file, one home per fact.** Duplicated facts are deleted, never synchronized. Superseded rules are repealed by name, never left to coexist.
5. **Truth everywhere.** A fabricated testimonial is the same sin as a fake alert. No unverifiable claim ships, ever — and no user is recruited into an alert path this document knows is dishonest.
6. **Demand before supply.** External users are the only scoreboard. Coverage work happens only when a real user (or a named strategic wedge) asks for a school.
7. **~Zero out-of-pocket.** The stdlib monolith, two-file scp, and free tiers ARE the architecture, not a compromise.
8. **Delegation is earned by artifacts, not by quiet.** At zero users, "no incidents" proves nothing; promotion evidence must include committed proof AND real external users in the measurement window. No gate closes on the attestation of the agent it constrains.

## Failure Recovery Playbook

- **Session dies:** all state lives in the repo, never scrollback. Boot a successor with one line: "Read CONSTITUTION.md, then BLOCKERS.md, then QUEUE.md, then git status/log; **confirm no other Build session is open**; you are Build." Two simultaneous Builds recreate the two-writers collision.
- **Watched school breaks:** health guard pages within ~2 minutes; the user's watch page shows "we can't currently read this school." Build repairs within 48h or removes the school with a closure notice to its watchers.
- **Unwatched rot:** nightly rot-sweep; weekly count in the brief; fix-or-remove. Never urgent, never invisible.
- **Semester boundary:** auto-roll is disarmed at ratification, so the boundary's failure mode is term-staleness, not watch-death — stale terms page you and (once built) notify users. Rolls resume, loud and guarded, only after gate ORD-A closes on your yes: guarded rolls execute and page; stranded watches notify their users; pinned bumps arrive as one-tap items.
- **Process/VM death:** dead-man check emails you within minutes. RUNBOOK.md rebuild: fresh free VM, clone repo, restore the newest Vault copy **from ~/SeatWatchVault/ on your Mac** (the drill restores from there, not the on-VM ring — and the first drill validates the ratification-day copy specifically), paste secrets from your password manager, systemd unit, repoint DNS — Build narrates, you paste. Drilled once, end-to-end, after ratification.
- **You are absent 2 weeks:** honest statement — interactive agents don't run without you, so broken schools stay safely dark (fail-closed) until you return; no gated item ships; healthchecks email still reaches you for true outages. Before planned absence: 10-minute pre-flight (clear the queue, confirm drill PASS, confirm backup freshness). This is a known limitation, not a covered case.
- **A false "open" reaches anyone:** report-link fires a PAGE → Build pauses the school immediately (automatic, no confirmation needed) → you confirm or clear on Build's evidence in DECISIONS.md → affected users notified → confirmed false-open re-gates school adds for 90 days → post-mortem entry. Rehearsed in prose now so it is never improvised later.
